# 双考航线

面向 2026 年 10 月 27 日雅思考试与 2026 年 12 月 12 日大学英语六级考试的每日学习清单。

## 使用

直接双击 `index.html` 即可使用；也可以在当前目录运行本地静态服务器：

```powershell
python -m http.server 5173
```

然后访问 `http://localhost:5173`。

## 功能

- 2026-09-24 至 2026-12-12 的逐日学习安排
- 雅思基础、提速、模考、收束与六级基础、强化、冲刺阶段
- 每日任务勾选、全天计划进度条、总航线进度
- 未完成任务在日期跨天后自动顺延到当天
- 独立“词汇声场”：使用“听力材料”文件夹中的场景高频词与机经词，每日 15 词、英式发音、逐字拼读、连续播放、听写模式
- 5.5 与 6.0 听写材料按阶段安排，任务卡可直接播放原训练音频
- 词汇掌握进度按日期与训练模式保存
- 按老师建议加入听力辨音/定位预测与阅读分篇计时/单题止损策略
- 浏览器本地保存、自定义任务、每日复盘笔记
- 25 / 45 / 60 分钟专注计时
- 周进度图、连续全清天数、进度 JSON 备份
- 手机端单手布局、底部快捷导航与安全区适配
- 已配置 PWA 清单、图标与离线缓存；通过 HTTPS 部署后可完整安装

## 手机使用

正式使用时，将 `dist/` 或 `双考航线-静态部署包.zip` 发布到 GitHub Pages、Cloudflare Pages 等 HTTPS 静态托管平台。发布后电脑关机也不影响手机访问。

详细步骤见 `DEPLOY.md`。

- 安卓 Chrome：浏览器菜单 → “安装应用”或“添加到主屏幕”。
- iPhone Safari：分享 → “添加到主屏幕”。
- 首次联网打开后，网页框架会缓存到手机，可在离线状态继续使用清单。
- 可以导出和导入 JSON 备份，在不同设备之间迁移进度。

> 数据保存在当前浏览器的 localStorage 中。清理浏览器网站数据会清空进度，请按需使用“备份进度”。
