# 听力练习书

把个人雅思听力资料整理成可以自主领取任务、练习词汇、完成听写与听音辨义测试的手机网页。

## 使用

直接双击 `index.html` 即可使用；也可以在当前目录运行本地静态服务器：

```powershell
python -m http.server 5173
```

然后访问 `http://localhost:5173`。

## 功能

- “听力练习书”目录：场景高频词、机经词汇、5.5 听写、6.0 听写和错词本
- 每次可自主设置领取 5 / 10 / 15 / 20 / 30 个词
- 自动路线先完成场景高频，再进入机经词汇，并由 5.5 听写逐步走到 6.0
- 当前任务没完成前不能重复领取；可回收未完成内容，下次优先接续
- 听音辨义测试：播放一个单词，随机给出四个中文选项
- 32 组 5.5 / 6.0 听写均可在听完后点击“显示答案”，查看教材原编号、拼写、音标和中文释义
- 测试错词自动进入错词本，记录总题量与正确率
- 云端账号：已有账号登录、跨浏览器/跨设备同步，每个账号的任务、词汇、错词和测试数据完全分开
- 旧版本创建的本机账号可在原设备一键升级为云端账号，完整保留当前任务与学习进度
- 云端账号登录后可修改密码，方便在其他设备重新登录
- 未配置云端时仍可使用本机账号和 JSON 备份
- 第一次创建账号时会把原有学习进度自动迁移到该账号
- 支持锁定、切换账号和修改当前账号密码
- 单词发音优先使用在线真人词典音频，手机浏览器无需系统语音包；在线源异常时才回退系统英文语音
- 训练 MP3 使用 Range 流式请求，点击后才加载，不再先下载整段音频
- 手机端适配、PWA 安装、本地进度保存、JSON 备份与导入

## 手机使用

正式使用时，将 `dist/` 或 `双考航线-静态部署包.zip` 发布到 GitHub Pages、Cloudflare Pages 等 HTTPS 静态托管平台。发布后电脑关机也不影响手机访问。

详细步骤见 `DEPLOY.md`。

- 安卓 Chrome：浏览器菜单 → “安装应用”或“添加到主屏幕”。
- iPhone Safari：分享 → “添加到主屏幕”。
- 首次联网打开后，网页框架会缓存到手机。
- 训练音频需要联网流式播放；学习进度可以导出和导入 JSON。

> 登录云端账号后，进度会保存到 Supabase，并在其他浏览器登录同一账号时恢复。本机同时保留一份缓存；仍建议定期使用“备份”。

## 开启跨浏览器同步

1. 创建免费 Supabase 项目。
2. 在 SQL Editor 运行 `supabase-setup.sql`。
3. 在 Authentication → Providers → Email 中开启 Email，并关闭 Confirm email。
4. 在 GitHub 仓库 Settings → Secrets and variables → Actions → Variables 中增加：
   - `SUPABASE_URL`：Supabase Project URL
   - `SUPABASE_ANON_KEY`：Supabase anon public key
5. 重新运行 GitHub Pages 工作流，网站就会显示可用的“登录已有账号”和“注册并进入”。

只可使用 `anon public key`，不要把 `service_role` 密钥放进网页。
